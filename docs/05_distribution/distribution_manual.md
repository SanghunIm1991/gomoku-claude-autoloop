# 配布マニュアル（スタンドアロン実行形式）

本書は、テスト工程完了済みの本アプリケーション（15×15五目並べ）を、配布方式として選択した
**スタンドアロン実行形式**（PyInstallerによる単一実行ファイル化）でパッケージングし、配布する
ための手順書である（配布方式の選定は`docs/qa_log.md`のユーザー決定を参照）。

関連する要件ID: CON-05（GUI実装はtkinterのみ使用）・CON-06（対応OSはWindowsのみ）・
CON-07（Python 3.11環境で動作）。スタンドアロン実行形式でパッケージングすることで、配布先の
実行環境にPython自体をインストールする必要がなくなる（CON-07が定める「Python 3.11環境」は
あくまで**ビルド時**の前提であり、配布物の実行時にはPythonのインストールを要求しない）。

## 1. ビルド環境

| 項目 | 内容 |
|---|---|
| OS | Windows 11 |
| Python | `py -3.11`（`C:\ProgramData\anaconda3\python.exe`、Python 3.11.5） |
| パッケージングツール | PyInstaller 6.22.0 |
| エントリーポイント | `src/main.py`（`main()`関数。COMP-01・FUNC-01） |

## 2. ビルド手順

### 2.1 事前準備（初回のみ）

1. PyInstallerをインストールする。

   ```
   py -3.11 -m pip install pyinstaller
   ```

2. anaconda3環境に、PyInstallerと競合する`pathlib`パッケージ（PyPI版の廃止済みバックポート、
   Python標準ライブラリの`pathlib`モジュールとは別物）が入っている場合は削除する。存在確認は
   以下で行う。

   ```
   py -3.11 -m pip show pathlib
   ```

   何か表示される場合は削除する（`C:\ProgramData`配下への書き込みとなるため管理者権限の
   ターミナルで実行する必要がある。詳細は本書「6. トラブルシューティング」参照）。

   ```
   py -3.11 -m pip uninstall -y pathlib
   ```

3. 準備ができたことを確認する。

   ```
   py -3.11 -m PyInstaller --version
   ```

   バージョン番号（例: `6.22.0`）が表示されれば準備完了。

### 2.2 ビルドの実行

プロジェクトルート（`D:\claudeProject2`）で以下を実行する。

```
py -3.11 -m PyInstaller --onefile --windowed --name Gomoku --paths src src/main.py
```

- `--onefile`: 依存ファイルをすべて1つの`.exe`にまとめる（スタンドアロン実行形式の要件）
- `--windowed`（`--noconsole`と同義）: GUIアプリのため、実行時にコンソールウィンドウを表示しない
- `--name Gomoku`: 生成される実行ファイル名を`Gomoku.exe`にする
- `--paths src`: `src/main.py`が`from game_logic import GameLogic`のように`src`直下の
  モジュールを相対パスなしでimportしている構成に対応するため、モジュール検索パスに`src`を
  追加する

ビルドが成功すると、プロジェクトルート直下に以下が生成される。

- `Gomoku.spec` — PyInstallerのビルド設定ファイル。**Gitで管理する**（再現可能なビルド手順として）
- `build/` — ビルド時の中間生成物。**Gitで管理しない**（`.gitignore`に追加済み）
- `dist/Gomoku.exe` — 配布対象となる実行ファイル本体。**Gitで管理しない**（`.gitignore`に
  `dist/`を追加済み。バイナリサイズが大きく、ソースから再現可能なため）

2回目以降のビルドは、`Gomoku.spec`を使って以下のように再現できる。

```
py -3.11 -m PyInstaller Gomoku.spec
```

### 2.3 ビルド後の動作確認

生成された`dist/Gomoku.exe`を実際に起動し、以下を確認する。

**自動確認（スモークテスト。本ビルドで実施済み）**

- プロセスが起動し、例外を出さずに存続すること（起動直後にクラッシュしないこと）
- 標準出力・標準エラー出力に例外・エラーメッセージが出力されていないこと

本ビルドでは、`dist/Gomoku.exe`をバックグラウンドプロセスとして起動し、数秒後にプロセスが
生存していること（`tasklist`で確認）、標準出力・標準エラー出力に何も出力されていないことを
確認した上でプロセスを終了させるスモークテストを実施し、問題がないことを確認済みである（本
プロジェクトの方針上、GUIのクリック操作等を自動化した検証は行わない）。

**手動確認（人間による目視確認を推奨。ビルドのたびに実施することが望ましい）**

- `Gomoku.exe`をダブルクリックして起動し、五目並べの盤面ウィンドウが表示されること
- 着手・勝敗判定・リスタートといった主要機能が、実装工程・テスト工程で確認済みの内容と同様に
  動作すること

## 3. 配布先の動作環境

- 対応OS: Windowsのみ（CON-06）。ビルド環境と同じくWindows 10/11を想定
- Pythonのインストール: **不要**。スタンドアロン実行形式のため、`.exe`ファイル単体で動作する
- 追加ライブラリのインストール: 不要（CON-05が定める通りGUIはtkinterのみに依存しており、
  PyInstallerがtkinter含め必要なファイルをすべて`.exe`内に同梱している）

## 4. 実行手順

1. `dist/Gomoku.exe`を配布先の任意のフォルダにコピーする（インストーラは不要。単一ファイルを
   配置するだけでよい）
2. `Gomoku.exe`をダブルクリックして起動する
3. 五目並べの盤面ウィンドウが表示されたら起動完了。以降の対局操作（着手・リスタート等）は
   `docs/01_requirements/requirements.md`の各要件通りに動作する

終了する場合はウィンドウを閉じる（×ボタン）。

## 5. 既知の注意事項

- **署名なしバイナリの警告**: `Gomoku.exe`は個人開発のため、コード署名（デジタル署名）を
  行っていない。そのため、初回実行時にWindows Defender SmartScreenが
  「Windows によって PC が保護されました」等の警告を表示する場合がある。この場合は、
  「詳細情報」をクリックしてから「実行」を選択することで起動できる。ウイルス対策ソフトに
  よっては同様に警告が出る場合があるが、これはコード署名がないこと自体に起因する一般的な
  挙動であり、実装・テスト工程で確認済みの通りアプリケーション自体に不正な処理は含まれない
- **起動がやや遅い場合がある**: `--onefile`形式は起動時に一時フォルダへ自己展開するため、
  通常のPythonスクリプト実行やディレクトリ形式（`--onedir`）のビルドと比べて初回起動に
  数秒程度時間がかかることがある。動作上の問題ではない

## 6. トラブルシューティング

### 6.1 `py -3.11 -m PyInstaller`実行時に「pathlibパッケージと競合するため実行できない」というエラーが出る

PyInstallerは、Python標準ライブラリの`pathlib`モジュールとは別物のPyPI版`pathlib`パッケージ
（廃止済みのバックポート）がインストールされていると、競合を検知して実行を拒否する仕様である。
以下の手順で解消する（本プロジェクトでも実際に発生し、下記の手順で解消した。詳細な経緯は
`docs/qa_log.md`の2026-08-13「配布（環境構築）」を参照）。

1. `py -3.11 -m pip show pathlib` で当該パッケージがインストールされていることを確認する
2. `py -3.11 -m pip uninstall -y pathlib` で削除する
   - anaconda3のインストール先（`C:\ProgramData\anaconda3`配下）への書き込み権限がないと
     `PermissionError`で失敗する。その場合は管理者権限のターミナルで再実行する
   - このパッケージはconda環境の`conda-repo-cli`が依存先として登録している場合があるが、
     Python 3.4以降は標準ライブラリの`pathlib`モジュールで代替されるため、削除しても通常の
     Python開発・本プロジェクトの動作には影響しない
3. `py -3.11 -m PyInstaller --version` でエラーが解消されたことを確認してからビルドを再実行する

### 6.2 ビルドした`.exe`が起動しない・すぐに終了する

- コンソールウィンドウを表示するデバッグ用ビルド（`--windowed`を外してビルドする）を作成し、
  エラーメッセージを確認する
  ```
  py -3.11 -m PyInstaller --onefile --name Gomoku_debug --paths src src/main.py
  ```
- `--paths src`の指定漏れにより、`src`直下のモジュール（`game_logic`等）のimportに失敗して
  いないか確認する
