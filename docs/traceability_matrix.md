# トレーサビリティマトリックス

要件定義書のID（REQ-xx / NFR-xx / CON-xx）を起点に、隣接する工程どうしの対応表を4つ用意する。各工程の成果物が確定し次第、行・列・○/IDを追記していく。

## ①要件×コンポーネント

| 要件ID | （コンポーネント設計工程で確定したコンポーネントIDを列に追加） |
|---|---|
| | |

## ②コンポーネント×関数

| コンポーネントID | （関数設計工程で確定した関数IDを列に追加） |
|---|---|
| | |

## ③関数×テスト（テストモジュール単位）

| 関数ID | （テストモジュールIDを列に追加。セルには該当テストIDを列挙） |
|---|---|
| | |

## ④要件×テスト（直接検証トレース、テストモジュール単位）

| 要件ID | （テストモジュールIDを列に追加。セルには該当テストIDを列挙） |
|---|---|
| | |

テスト工程完了時には、④の全要件ID（REQ/NFR/CON）の行に最低1つのテストIDが記載されていることを確認し、網羅性チェックとする。
